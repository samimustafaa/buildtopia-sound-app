# BuilTopia Sound

Choose which BuildTopia weapon sounds to use in Creative Destruction.

1. [Download the latest installer](https://github.com/samimustafaa/buildtopia-sound-app/releases/latest).
2. Close the game, connect its folder, select weapons, and click **Apply changes**.
3. Close the app. Your sounds stay installed.

**Restore all CD sounds** brings back the included original `wwise.npk`. No game reinstall needed.

Updates: **Settings → Check for updates → Update & restart**.
