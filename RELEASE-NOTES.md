# sg0hann SoundSwap 1.1.0

- Automatic update checks and a popup when a newer Windows release is ready.
- Settings → Check for updates.
- **After applying sounds, you can fully close SoundSwap. Sounds keep working without the app running.**
- Compact dark amber design, individual sound selections, previews, backups and restore.

Download the Windows ZIP, extract the **entire ZIP**, and open **sg0hann SoundSwap.exe**. Close the game, choose its folder, select sounds and Apply. Then close SoundSwap and launch the game normally.

Future updates download through your browser. Close SoundSwap and extract the entire new ZIP into a new folder. Updates are not installed automatically. Install this version once to receive future update notifications; version 1.0.0 has no updater.

Archive and update-checker tests pass. Real Windows process enumeration and gameplay still need testing. Weapon badges reflect earlier user tests; vehicles and traps still need gameplay testing. Artwork remains replaceable placeholder imagery.
