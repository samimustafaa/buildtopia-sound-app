# sg0hann SoundSwap 1.2.0

## Download

Download **sg0hann-SoundSwap-1.2.0-Setup.exe**, close SoundSwap, and run it. One installer creates a desktop and Start menu shortcut. Runtime files stay in the installation directory; no folder of DLLs to extract or manage. Later installers update the same installation and keep settings, custom images and backups.

## Game artwork

- Added all 24 supplied game images. Matching sound cards now show the correct compact artwork, with both 92F and P229 on their shared card.
- Updated display names from the supplied images: S1897, P357, PL, M5, MGL, RPG7 and X-1. Sound-bank routing is unchanged.
- C111 is available in Settings → Included game images. Its sound mapping remains unconfirmed.

## Updates

Update popups now prefer Setup.exe. Close the app and run the downloaded installer. For users on 1.1.0, the compatibility Windows ZIP contains the same Setup.exe and a short instruction file. Updates are not silently installed.

**After applying sounds, fully close SoundSwap. Sounds keep working without it running.**

Existing weapon test results remain unchanged. Real gameplay testing is still needed for untested weapons, vehicles and traps.
